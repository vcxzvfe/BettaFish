### **反向交易信号深度分析报告模板**

- **1.0 执行摘要**
  - 1.1 话题概览与监测周期
  - 1.2 反指信号强度（Contrarian Score）核心结论
  - 1.3 推荐操作摘要（卖出 / 做空 / 减仓 / 观望）
  - 1.4 信号有效期与下次复核节点

- **2.0 舆情扩散与破圈分析**
  - 2.1 主题溯源（最早发布平台/账号/时间戳）
  - 2.2 传播链路解构（KOL → KOC → 普通用户的层级流转）
  - 2.3 破圈速度 V(t) 估算（每日新增独立作者数 × 跨社区扩散熵 H）
  - 2.4 多平台扩散热图（小红书 / 抖音 / 微博 / B站 / 快手 / 知乎 / 贴吧 / X 共振度）
  - 2.5 V'(t) 一阶导数趋势：加速 → 减速 → 见顶判定

- **3.0 情绪饱和度评估**
  - 3.1 情感极性分布（极端正面 / 正面 / 中性 / 负面 / 极端负面 占比）
  - 3.2 7 日情绪饱和度 S = (极端正占比 − 极端负占比) 的 z-score
  - 3.3 高频关键词与典型语料样本
  - 3.4 情绪饱和度异常阈值告警（|S| > 2σ 时触发）

- **4.0 共识度与分歧分析**
  - 4.1 评论极性方差 D（值越低共识越强）
  - 4.2 质疑/反对声音占比与典型反对论点
  - 4.3 KOC 共识度（普通用户口径趋同程度）
  - 4.4 共识度骤降到历史 10 分位的反指信号触发判定

- **5.0 反指信号综合评估**
  - 5.1 Contrarian Score 综合公式：V'(t) × |S| × (1 − D)
  - 5.2 三段判断模型：萌芽期（单社区低 V）→ 扩散期（V/H 上升）→ 破圈期（V' 转负 + H 饱和 + D 骤降）
  - 5.3 历史相似话题反指案例对照（同主题 / 同行业 / 同情绪饱和度）
  - 5.4 信号置信度分级（高 / 中 / 低 / 噪音）

- **6.0 资产标的映射**
  - 6.1 直接关联标的（A股 / 港股 / 中概美股 / 加密货币 / 商品）
  - 6.2 间接关联标的与产业链上下游
  - 6.3 标的当前估值水位、机构持仓拥挤度、近期资金流向
  - 6.4 已被市场 price-in 的程度评估

- **7.0 反向操作建议与风险管理**
  - 7.1 反向操作建议（具体方向：做空 / 卖出 / 减仓 / 观望 / 反向 ETF）
  - 7.2 入场窗口与触发条件（破圈拐点确认后的 N 个交易日内）
  - 7.3 退出条件（情绪饱和度回落、共识破裂、价格目标位）
  - 7.4 建议仓位与止损止盈比例
  - 7.5 关键风险因素（信号误判 / 政策黑天鹅 / 流动性风险 / 反向 squeeze）
  - 7.6 后续监测节点（接下来 N 天重点观察的指标与平台）

- **8.0 数据透明度与方法论披露**
  - 8.1 本次分析采用的平台与抓取窗口
  - 8.2 样本量与代表性说明
  - 8.3 模型假设与已知盲区
  - 8.4 信号回测有效性参考（历史命中率）
